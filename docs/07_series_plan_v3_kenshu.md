# 연재 기획 v3 — 「コリアナ社内研修ノート、特別公開」 → 成分ノート

## 컨셉: 먼저 베푼다 (Give first)
- 1988년 창업, 40년 가까이 된 한국 화장품 회사 코리아나의 **사내 교육 자료를 독자에게 살짝 공개**하는 느낌
- 앞부분은 제품을 팔지 않고 지식만 줌 → 신뢰가 쌓인 뒤 「그래서 이 앰플을 만들었다」로 성분노트 연결

## 시리즈명 후보
1. 「コリアナ社内研修ノート、こっそり公開します」 ← 추천 (친근함 + 특별함)
2. 「韓国コスメメーカーの社内研修、特別に見せちゃいます」
3. 「創業1988年・コリアナの“門外不出”スキンケア講座」 (임팩트 강하지만 과장 느낌 주의)

## 표기 주의
- 「40年」: 창업 1988년 → 2026년 기준 38년. 「40年」 단정은 景表法상 부정확 → 「創業1988年」「40年近く」 사용
- 「몰래/こっそり」는 연출 톤으로만 사용. 공식 블로그 게재이므로 실제로는 **회사 승인 하에 공개** (사내 승인 확인 필요)

## 구성: 2단계, 총 약 20회 / 약 7주 (주 3회)

### Phase 2. 成分ノート (13회, 약 4.5주)
- 각 회 첫머리에 「研修ノートのおさらい」 3줄 → 해당 研修회 링크 (블로그 내 회유 ↑)
  - 예: VCショット ← 研修1(ターンオーバー) / セラミド ← 研修5(バリア) / ペプチド2X ← 研修6(ハリ)
- 순서: 01 ヒアルロン → 02 ペプチド2X(楽天1位) → 03 セラミド → 04 ハイパーセラミド → 05 VC → 06 ブレミ → 07 エンタングル → 08 ハイパーペプチド → 09 アクネ → 10 ハイパーシカPDRN → 以降 + SP(悩み別早見表・朝夜ルーティン)

## 왜 10주 → 약 7주로 줄였나
- 자료 30p 중 실제 주제는 7개 정도. 10회로 늘리면 1~2장짜리 슬라이드로 글 1편을 채워야 해서 내용이 얇아짐
- 지식을 앞에 몰아서 짧고 밀도 있게 → 독자가 「다음 편」을 기다리는 연속성 확보
- 주 1회씩 10주 분산하면 지식 글 사이 간격이 길어 「특별공개」 몰입감이 떨어짐
