## 확정 사항 (2026-11-01)
- 대상: 샷 앰플 + 하이퍼샷 3종 포함
- 발행: 아메바 블로그(AMPLE:N 공식) 수동 발행 / 주 3회 (월·수·금 제안)
- 전달: Google Drive `AMPLE:N アメブロ連載/No.xx_제품명/` 폴더에 본문 Doc + 이미지 3장
- 디자인: 흰 배경 + 손글씨(Klee One / Yomogi, OFL 라이선스), 앰플별 테마 컬러
- 라쿠텐 링크: 미정 → 본문에 `{{RAKUTEN_LINK_xxx}}` 자리표시

## 화자(페르소나) 제안
- 「AMPLE:N公式スタッフ」 1인칭, です・ます체, 친근하지만 성분 설명은 정확하게
- 공식 블로그이므로 "광고임"은 자명 → 글머리에 公式ブログ 명시 + 어필리에이트 사용 시 広告 표기
- 효능 표현은 薬機法 화장품 56항목 범위만 사용 (치료·개선 단정 금지)

## 회차당 구성 (고정 포맷)
1. 인사 + 연재 소개(짧게)
2. 이미지① 성분 노트 → 핵심 성분 3개 설명
3. 이미지② 일본 스킨케어 순서에서의 사용 타이밍(朝/夜)
4. 이미지③ 이런 고민에 추천 + 함께 쓰면 좋은 앰플
5. 정리 3줄 + 라쿠텐 링크 + 다음 회 예고
