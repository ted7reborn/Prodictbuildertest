## 2. 연재 구조 제안: 2트랙
- **월요일 = 「肌の基礎ノート」(신규)**: 자료 기반 스킨케어 지식 1주제 → 마지막에 그 주 수·금 소개할 앰플 예고
- **수·금 = 「成分ノート」(기존)**: 앰플 1종씩 성분·사용 타이밍·고민
- 효과: 지식 글로 검색 유입(「洗顔 やり方」「ターンオーバー」 등 일본 검색량 큰 키워드) → 제품 글로 연결 → 라쿠텐 랜딩. 공식 블로그의 전문성·신뢰도 상승

## 4. 일본 게재 시 변환 규칙 (자료 표현 → 블로그 표현) ★중요
자료는 한국 사내 교육용이라 그대로 쓰면 일본 薬機法 위반이 되는 표현이 있음.
| 자료 표현 | 일본 블로그에서는 |
|---|---|
| 피부 재생 촉진 / 세포분열 촉진 | ✕ 사용 불가 → 「肌にうるおいを与える」「すこやかに保つ」 |
| 콜라겐·엘라스틴 생성 촉진 (펩타이드) | ✕ 제품과 연결 불가 → 성분 일반 지식으로만 설명 + 제품은 「ハリを与える」 |
| 부작용·독성이 없음 | ✕ 안전성 보증 표현 금지 → 삭제 |
| 주름 개선 / 주름 예방 | ✕ → 「乾燥による小じわを目立たなくする」(효능평가 시험 완료 제품만) |
| 기미·잡티 개선, 미백 | ✕ (의약부외품만) → 「メイクアップ効果によりくすみをカバー」 등은 제품 성격에 따라 / 기본은 「明るい印象に」 |
| 모공 수축 | △ → 「肌を引きしめる」 |
| 피부암 유발 (자외선) | 일반 지식으로 「紫外線は肌ダメージの原因に」 정도로 완화 |
| 연령별 콜라겐 88/85/75/50%, 히알루론산 80% 감소, 평생 각질 48kg 등 수치 | 출처 확인 전 사용 보류 (출처 있으면 「※○○調べ」 명기) |

- 자료의 그림·사진(해부도, 모델 사진, 스톡 사진)은 저작권 문제로 재사용하지 않고 **손글씨 도식으로 새로 그림**
- 자료 속 타사/그룹 브랜드(NOKDU, SENITE, LAVIDA, preange 등)는 블로그에서 언급하지 않음 (AMPLE:N 공식 블로그)
