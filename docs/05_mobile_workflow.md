# 핸드폰만으로 운영하는 방법

Claude 작업은 전부 클라우드에서 돌아가므로 **PC 없이 핸드폰으로 진행 가능**.

## 회차마다 흐름
1. **Claude 앱**(Code 탭)에서 이 프로젝트 세션을 열고 요청
   - 예: 「No.04 하이퍼샷 세라마이드 만들어서 드라이브에 올려줘」
2. Claude가 원고 + 손글씨 이미지 생성 → 드라이브 `AMPLE:N アメブロ連載/No.xx_.../` 에 자동 업로드
3. **Google 드라이브 앱**에서 확인
   - 이미지: 파일 열기 → ⋮ → 「다운로드」(또는 「사본 보내기 → 이미지 저장」) 로 사진첩에 저장
   - 본문: 구글 문서 열기 → 길게 눌러 전체 선택 → 복사
4. **アメブロ 앱**에서 새 글 작성
   - 제목 붙여넣기 → 본문 붙여넣기 → 【画像 …】 자리에 사진첩 이미지 삽입 → 해시태그 입력 → 投稿

## 주의
- 환경변수(DRIVE_UPLOAD_URL/TOKEN)는 이미 등록되어 있어 추가 설정 불필요
- Apps Script 코드를 수정한 경우에만 PC에서 재배포 필요 (평소엔 불필요)
